🎃 Halloween Website
📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um site temático de Halloween.

A proposta foi desenvolver uma página web com identidade visual inspirada no Halloween, explorando elementos visuais e componentes que remetem à temática, proporcionando uma experiência interativa e agradável ao usuário.

💻 Tecnologias utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias:

HTML5: estruturação e organização do conteúdo da página.
CSS3: estilização, personalização visual e layout do site.
JavaScript: implementação de funcionalidades e interatividade.
Bootstrap: framework utilizado para auxiliar na construção do layout responsivo e na organização dos componentes.
🎯 Objetivo

Aplicar na prática os conhecimentos adquiridos durante o desenvolvimento acadêmico, trabalhando com tecnologias fundamentais para o desenvolvimento web front-end.

🚀 Funcionalidades
Interface temática inspirada no Halloween.
Layout estilizado e organizado.
Elementos visuais personalizados.
Recursos de interatividade com JavaScript.
Estrutura adaptável a diferentes tamanhos de tela.

📚 Contexto acadêmico
